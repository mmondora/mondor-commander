# Mondor Commander

Norton Commander-style directory analyzer and comparator with a retro DOS web interface.

## Project

The main project lives in [`mondor-commander/`](mondor-commander/). See its [README](mondor-commander/README.md) for usage, installation, and documentation.

## Quick Start

```bash
cd mondor-commander
npm ci
node bin/mc.js /path/to/dir1 /path/to/dir2
```

## Legacy

The original Python prototype (`dirdiff.py`) has been superseded by the Node.js implementation.
